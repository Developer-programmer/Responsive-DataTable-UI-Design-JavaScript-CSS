# Fieldnotes Accounts

A responsive account directory built with vanilla JavaScript, custom CSS, and Bootstrap 5.3. It includes searchable and sortable account records, status filters, pagination, CSV export, and a form for adding accounts.

## Run

Open `index.html` in a browser. Bootstrap, Bootstrap Icons, and the display fonts load from CDNs, so an internet connection is needed for those assets. The table itself is built with local HTML, CSS, and JavaScript.
